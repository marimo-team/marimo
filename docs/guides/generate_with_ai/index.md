# Using AI with marimo notebooks

## Using coding agents

**For the best experience, use [marimo pair](marimo_pair.md).** [marimo
pair](marimo_pair.md) gives agents like Claude Code, Codex, and OpenCode full
access to your marimo notebooks. Paired agents can do anything you can do and
more: read variables, test logic in a scratchpad, run cells, read UI element
values, and more. marimo pair lets you work on your notebook side-by-side with
an agent, letting you move seamlessly between your agent's UI or CLI and the
marimo editor.

**For tasks like converting Jupyter notebooks to marimo, use [skills](skills.md).**  Install [skills](skills.md)
for specific tasks, such as converting notebooks from Jupyter to marimo or
writing high-quality anywidgets.

## Using the marimo editor

**For small edits, use the marimo editor's [built-in AI features](../editor_features/ai_completion.md).** The marimo
editor comes with [AI-assistance features](../editor_features/ai_completion.md): a
chat sidebar, cell generation and refactoring, and inline copilots, connected to
the LLM provider of your choice. The assistant is data-aware, with access to
the values of variables in memory. Use these features for small edits, or
if you are uncomfortable using coding agents.
