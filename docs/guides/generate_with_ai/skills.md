# Skills

Install our official skills with a single command using [uv](https://docs.astral.sh/uv/):

```bash
uvx deno -A npm:skills add marimo-team/skills
```

For the best experience, use these skills alongside [marimo
pair](marimo_pair.md), which lets your agent interact with
running notebooks.

**Use cases.** Use these skills for specific tasks, such as:

- convert Jupyter notebooks or other artifacts to marimo notebooks;
- make bespoke interactive widgets for specific use cases using anywidget.

**Feedback.** We welcome feedback at our [GitHub repository](https://github.com/marimo-team/skills/issues).
